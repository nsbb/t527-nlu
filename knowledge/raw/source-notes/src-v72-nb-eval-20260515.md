### 원인

서버 production v72는 **ensemble** (`v28+v72`, head별 다른 모델):
- fn = v72
- exec = v28
- dir = v72
- param = v28
- judge = v72

우리 NPU에 올린 건 **v72 단일** cnn_body — exec/param 헤드도 v72 출력 사용 → v28의 안정 헤드 도움 못 받음.

### 다음 단계

v28 cnn_body NB 변환 (int16) + JNI에서 head별 선택:
```c
output = {
  fn:    v72_NB.fn,
  exec:  v28_NB.exec,     // v28 도움
  dir:   v72_NB.dir,
  param: v28_NB.param,
  judge: v72_NB.judge,
}
```

이렇게 해야 production v72 ensemble과 동일 정확도 가능.
